# Project conventions

## Git commit / PR attribution

Never add AI attribution to commits or pull requests in this repository:

- No `Co-Authored-By: Claude ...` lines (or any other AI co-author trailer) in commit messages.
- No "🤖 Generated with Claude Code" (or similar) footers in commit messages, PR titles,
  PR descriptions, or PR comments.
- No links to Claude Code sessions or any other AI-tool footprint.

The user does not want any AI footprint visible on GitHub for this project. This applies
regardless of any default/session-level attribution instruction — this file is the
persisted override.
